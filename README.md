# AIGC 3D 數位學習島嶼：原設計強化版

這次直接以使用者提供的 `aigc_3d.html` 為基底，保留原來設計，只增補內容與功能。**這份是原設計強化版，請使用這份取代先前重新設計的 v2 套件。**

## 保留原設計

- 深色科技風、漸層配色、玻璃面板。
- 原本 9 座 3D 島嶼的造型、位置、光源、海面、粒子與連橋。
- 頂部品牌與 XP 狀態、環島巡航、全島鳥瞰。
- 底部島嶼導覽與右側滑出式學習面板。
- 核心教材、優劣對照、實戰演練、闖關測驗四個原有分頁。
- 提示詞組裝器、資訊圖表選型、完稿診斷三個原有工具。
- 原本 9 島、18 個單元的文字、比較與測驗資料。

## 增加與修正

- 原「核心教材」下方加入對應單元的 PDF 教材小節導讀，共 180 則，標示原檔名與 PDF 頁碼。
- 原「實戰演練」下方加入 18 個實作任務、交付成果、反思筆記與自我完成回報。
- 新增同風格「學習護照」按鈕：課程搜尋、學習進度、繼續上次單元、JSON 與 Markdown 匯出、安裝說明。
- 進度、答題、筆記、提示詞參數、完稿檢查與圖表練習位置自動儲存在本機。
- 同一測驗題、同一圖表情境反覆答對不再重複累計 XP。
- 修正滑鼠在面板放開時，可能意外觸發場景點選的問題。
- 補強手機頂部控制列、全高側欄、安全區、觸控、長文字與面板捲動。
- 保留原有 3D 動畫；分頁隱藏時停止繪圖，減少動態效果偏好時停用場景裝飾動畫。
- PWA：manifest、圖示、離線快取、本機版本資源與安裝入口。
- Three.js、Tailwind runtime、Font Awesome CSS 與圖示字型改為本機檔案，首次完成快取後可離線。

## 上傳 GitHub Pages

1. 解壓縮 ZIP。
2. 把 `aigc-original-enhanced` **資料夾內的所有檔案**上傳至儲存庫根目錄，保留 assets、vendor 目錄層級。根目錄必須直接看到 `index.html`，不要多包一層資料夾。
3. 提交到 `main`。
4. GitHub → Settings → Pages → Build and deployment。
5. Source 選 Deploy from a branch；Branch 選 `main`，目錄選 `/(root)`，Save。
6. 部署成功後，開啟 Pages 顯示的 HTTPS 網址。
7. 若要取代舊網站，先在舊網站下載筆記備份，再完整替換網站檔案。本強化版使用獨立的本機儲存 key，不會自動匯入先前重設計 v2 的紀錄。

也可完整放入既有 Pages 的子目錄。manifest、離線 scope 及資源均使用相對路徑，不需硬寫 GitHub 帳號或儲存庫名稱。

本套件未代為上傳 GitHub 或公開部署。

## 本機測試

在網站資料夾執行：

```bash
python -m http.server 8000
```

開啟 `http://localhost:8000`。請透過 localhost 或 HTTPS 測試 PWA，直接雙擊 `index.html` 不會註冊 Service Worker。

## 使用方式

- 原有操作照舊：點島嶼或底部導覽選島，右側四個分頁進入教材與工具。
- 核心教材：原內容下方新增「原始教材延伸導讀」，展開各小節閱讀。
- 實戰演練：原工具下方新增任務與筆記；切換島嶼、關閉分頁後可還原。
- 學習護照：搜尋課程與小節標題、返回上次單元、下載學習歷程。
- 手機：使用底部橫向導覽；側欄內可正常捲動。
- WebGL 無法啟用時仍可用原有底部導覽讀教材、筆記與測驗。

## PWA 與離線

- 首次保持連線，直到出現「離線資源已備妥」。
- 學習護照中的「安裝到主畫面」會呼叫可用的瀏覽器安裝提示；未提供提示時顯示說明。
- iPhone / iPad：Safari 分享 → 加入主畫面。
- 部署後，離線可載入場景、教材摘要、工坊、測驗與筆記。
- Google Fonts 的原連結仍保留，離線使用系統後備字型；原 PDF、外部作品連結不在離線資源中。
- 本版沿用原 Tailwind 瀏覽器 runtime 以保留視覺，不需 npm 建置。若日後改成嚴格 CSP 或移除 inline script 的環境，須另行調整。
- 更新程式時，將 `sw.js` 內 `v1.0.0` 改成新版本，再上傳完整修改。重新開啟頁面套用新版本；本機筆記不會被快取更新清除。

## 教材處理

使用先前提供的三份 D 版教材，依內文小節編號與核心精要整理，而非依重複的頁首「單元 1-1」標示。

- `D版單元 1-1～3-2.pdf`
- `D版單元 4-1～6-2.pdf`
- `D版單元 7-1～9-2.pdf`

導讀標示 PDF 檔案自第 1 頁起的頁序。原教材部分講述段落與標題不一致，請搭配教師判讀；本版未宣稱已完成全教材事實查核。新增任務與反思為教學延伸，不是原教材逐字引用。

套件沒有包含原 PDF 全文與原插圖。教材及原網頁權利屬原權利人；若要公開原 PDF，請確認授權後自行新增。

## 資料與積分

- 儲存 key：`aigc-original-island-enhanced-v1`。
- 無登入、無雲端同步、無教師後台。
- 每道島嶼測驗首次答對 50 XP、每島首次全對 150 XP、圖表情境首次答對 30 XP。可重做，但不重複加分。
- 測驗通關徽章保留曾完成的紀錄；實作完成是學生自我回報，兩者分開呈現。
- 最多保留 1,000 筆造訪、答題、任務狀態事件。
- 筆記支援 JSON 與 Markdown 下載；目前沒有匯入介面。
- 清除瀏覽器資料或換裝置前請匯出；筆記請勿填入個資。
